* Главната идея

    Ще трябва да се направи интелигентна платформа за търсене на работа, която използва алгоритми за съвпадение и анализ, за да свърже кандидатите с идеалните за тях позиции

    Платформата ще поддържа:
    - Регистрация на кандидати и потребители
    - Публикуване на обяви
    - Търсене на най-подходящи кандидати/обяви по зададена стратегия 
    - Анализ на сходни профили и липсващи умения

* Skill (Умения)

    Следния (record) съдържа:
    - String name (не трябва да е Null Или Blank)
    - int level (0 няма опит, а 5 е експерт)
    # Ако валидацията е неуспешна да се хвърли IllegalArgumentException

* Candidate (Кандидат за работа)

    Следния (клас) съдържа:
    - String name (не трябва да е Null Или Blank)
    - String email (не трябва да е Null Или Blank)
    - Set<Skill> skils (не трябва да е null или empty)
    - Education education 
    - int yearsOfExperience (неотрицателни)
    # Ако валидацията е неуспешна да се хвърли IllegalArgumentException

* Employer (работодател)

    Следния (record) съдържа:
    - String companyName (не трябва да е Null Или Blank)
    - String email (не трябва да е Null Или Blank)
     # Ако валидацията е неуспешна да се хвърли IllegalArgumentException

* JobPosting (Обява за работа)

    Следния (клас) съдържа:
    - String id (не трябва да е Null Или Blank)
    - String title (не трябва да е Null Или Blank)
    - String employerEmail (не трябва да е Null Или Blank)
    - Set<Skill> requiredSkills (не трябва да е null или empty)
    - Education requiredEducation 
    - int requiredYearsOfExperience (трябва да е неотрицателно)
    - double salary (трябва да е неотрицателно)
     # Ако валидацията е неуспешна да се хвърли IllegalArgumentException

* CandidateForMatch (Съвпадение кандидат-позиция)

    Следния (клас) съдържа:
    - Candidate candidate (ще гледаме да не е null)
    - JobPosting jobPosting (ще гледаме да не е null)
    - double similarityScore (трябва да е в интервала [0,1])
    # Ако валидацията е неуспешна да се хвърли IllegalArgumentException

* SkillsRecommendation (Препоръка за умение)

    Следния (record) съдържа:
    - String skillName (да не е null или blank)
    - double improvementScore (неотрицателен)
    # Ако валидацията е неуспешна да се хвърли IllegalArgumentException

* Platform PlatformStatistics (Статистики на платформата)

    Следния (record) съдържа:
    - int totalCandidates (неотрицателно)
    - int totalEmployers (неотрижателно)
    - int totalJobPostings (неотррицателно)
    - String mostCommonSkillName (да не е empty или blank)
    - String highestPaidJobTitle (да не е empty или blank)

* Education 

    Същестуват няколко форми на образованието:
    - HIGH_SCHOOL
    - BACHELOR
    - MASTERS
    - PHD

* Алгоритми за сходство

    Ще има интерфейс (SimilarityStrategy), който ще се имплементира от:
    - JaccardSimilarity
    - CosineSimilarity
    
    Този интерфейс има само един метод:
    - double calculateSimilarity(Set<Skill> candidateSkills, Set<Skill> jobSkills);
    # Трябва да върне число между [0,1]

* Jaccard Similarity 

    Това е единият от двата класа, който трябва да имплементира (SimilarityStrategy), работи на този принцип
    J(A, B) = |A ∩ B| / |A ∪ B| 
    # Знака посредата е деление, тоест мощността на сечението делено на мощността на обединението
    
    Ако и двете множества са празни, тогава Jaccard = 0
